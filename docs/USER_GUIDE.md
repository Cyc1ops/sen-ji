# 森记使用指南

## 快速开始

### 1. 创建第一个计划

1. 打开森记应用
2. 点击左侧导航栏的"设置"
3. 点击"创建新计划"按钮
4. 输入计划名称（例如：森林四号计划）
5. 输入初始时间（例如：1000:00，表示1000小时）
6. 点击"创建"

### 2. 添加奖励任务

1. 点击左侧导航栏的"任务池"
2. 点击"添加任务"按钮
3. 输入任务名称（例如：完成森记应用开发）
4. 输入奖励时间（例如：5:00，表示5小时）
5. 点击"添加"

### 3. 完成任务

当你完成某个任务时：

1. 进入"任务池"页面
2. 找到对应的任务
3. 点击"完成"按钮
4. 系统会自动记录到今天的记录中

### 4. 每日记录

每天早上复盘昨天的专注时间：

1. 进入"记录"页面
2. 选择日期（通常选择"昨天"）
3. 输入专注时间（例如：7:41，表示7小时41分钟）
4. 点击"创建记录"或"更新记录"
5. 系统会自动计算剩余时间

### 5. 查看历史

查看过往记录：

1. 进入"历史"页面
2. 切换"列表视图"或"日历视图"
3. 点击某条记录查看详情

## 核心功能详解

### 仪表盘

仪表盘显示：
- 当前计划的进度条
- 剩余时间
- 今日统计（专注时间、完成任务数、奖励时间）
- 最近7天的记录

### 任务池

任务池用于管理所有的奖励任务：
- **添加任务**：设置任务名称和奖励时间
- **编辑任务**：修改任务信息
- **完成任务**：点击完成后自动记录到当天
- **删除任务**：软删除，不会影响历史记录

### 记录

记录页面用于输入每日的专注时间：
- **选择日期**：可以选择昨天、今天或自定义日期
- **查看已完成任务**：显示当天已完成的奖励任务
- **输入专注时间**：记录当天的专注学习时间
- **补记功能**：可以补录历史日期的记录

### 历史

历史页面提供两种查看方式：

**列表视图**
- 显示所有历史记录
- 每条记录显示日期、专注时间、完成任务、剩余时间
- 点击记录查看详情

**日历视图**
- 以日历形式展示记录
- 有记录的日期会高亮显示
- 点击日期查看详情

### 设置

设置页面包含：
- **计划管理**：创建新计划、归档完成的计划
- **数据导出**：导出为 Markdown 或 JSON 格式
- **关于信息**：查看应用版本和信息

## 使用技巧

### 时间格式

所有时间输入使用 `HH:MM` 格式：
- `7:41` = 7小时41分钟
- `1000:00` = 1000小时
- `0:30` = 30分钟

### 工作流程建议

**日常使用流程：**

1. **完成任务时**：立即在任务池中标记完成
2. **第二天早上**：
   - 查看滴答清单统计的昨日专注时间
   - 打开森记，进入记录页面
   - 输入昨日专注时间
   - 查看仪表盘了解进度

3. **每周回顾**：
   - 进入历史页面
   - 查看本周的记录
   - 分析专注时间分布

### 补记说明

如果某天忘记记录：

1. 进入"记录"页面
2. 点击"自定义日期"
3. 选择需要补记的日期
4. 输入专注时间
5. 保存记录

### 多计划管理

森记支持多个计划：

1. 完成当前计划后，在设置中归档
2. 创建新计划（例如：森林五号计划）
3. 每个计划的数据独立存储
4. 可以随时导出归档计划的数据

## 数据导出

### Markdown 格式

导出的 Markdown 格式类似：

```markdown
# 森林四号计划

初始时间: 1000:00
当前剩余: 986:19

---

## 2025-10-14

1000:00 - 7:41 - 5:00 - 1:00 = 986:19

完成任务:
- 完成森记应用开发 (-5:00)
- 学习摄影后期处理 (-1:00)
```

### JSON 格式

JSON 格式包含完整的数据结构，可用于：
- 数据备份
- 数据迁移
- 二次开发

## 常见问题

**Q: 如何修改已记录的数据？**
A: 进入"记录"页面，选择对应日期，修改专注时间后保存即可。

**Q: 删除任务后历史记录会丢失吗？**
A: 不会。删除任务只是软删除，历史记录中仍会保留任务名称和奖励时间。

**Q: 可以同时运行多个计划吗？**
A: 每次只能有一个活动计划，但可以创建多个计划并在它们之间切换。

**Q: 数据存储在哪里？**
A: 数据存储在应用的用户数据目录中的 SQLite 数据库文件。

**Q: 如何备份数据？**
A: 在设置页面使用"导出为 JSON"功能，保存完整的数据备份。
